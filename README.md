# Phishing Email Detection Model

## Project Description
A Machine Learning-based Phishing Email Detection System developed using Python. It identifies whether an email message is Phishing or Safe.

## Technologies Used
- Python
- Machine Learning
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Features
- Email text analysis
- Phishing email detection
- Safe email detection
- Machine Learning model training
- Accuracy calculation
- Confusion matrix visualization

## Project Files
- dataset.csv
- train_model.py
- predict.py
- model_results.txt

## Algorithm
Multinomial Naive Bayes

## How to Run

1. Install required libraries.
2. Run `python train_model.py`.
3. Run `python predict.py`.
4. Enter an email message to check its classification.

## Output
The system predicts whether the entered email is Phishing or Safe.
